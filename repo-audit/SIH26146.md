## 3. Component Deep Dive

### Strongest Components
1. **Domain-Complete 14-Field Ingestion & Enrichment Pipeline**:
   - Directly maps to NTRO Problem Statement 5 requirements.
   - Pydantic v2 models validate 64-character hex TXIDs, IPv4/IPv6 formats, port ranges, array lengths, and script types (`P2PK`, `P2PKH`, `P2SH`, `P2WPKH`, `P2TR`).
   - Local MaxMind GeoIP enrichment accurately annotates country code and autonomous system number without network access.
2. **Deterministic Laundering Motif Detectors**:
   - `detect_peeling_chains.py` accurately captures the classic Bitcoin peeling chain: one input, one small peeled output, one large change output propagating across $\ge 5$ hops.
   - `detect_coinjoin.py` reliably identifies mixing transactions via multi-party equal-output matching within $\pm 1\%$ relative tolerance.
3. **Rigorous Test Suite (26 Pytest Suites)**:
   - Sets the benchmark for forensic validation: duplicate ingestion idempotency, GeoIP degradation on missing databases, feature extractor invariants, and detector precision.

### Weakest Components
1. **Severe Infrastructure Bloat (The "4-Daemon Dilemma")**:
   - Requires running PostgreSQL, Neo4j, Redis, and Celery simultaneously. If any one container fails or exhausts memory on an ordinary Linux/laptop environment during an exam or evaluation viva, the whole system crashes.
2. **Next.js 16 SSR Overhead**:
   - Modern Next.js requires Node.js runtime servers and complex server-action builds that introduce unnecessary failure modes compared to a precompiled static Vite SPA served directly from FastAPI.
3. **Unlicensed Status**:
   - As an unlicensed proprietary repo, no direct copy-paste of code is permissible under clean-room engineering rules.

## 7. Integration Risks & Mitigation
- **Risk 1: Fatal Container Startup Failure**: Neo4j JVM heap allocation fails on 4GB/8GB RAM systems.
  - *Mitigation*: Completely eliminate Neo4j in NEXUS-BTC. Execute all graph algorithms in NetworkX and store records in SQLite/DuckDB.
- **Risk 2: Multi-Container Networking Issues**: Localhost vs Docker port conflicts.
  - *Mitigation*: NEXUS-BTC runs as a single, self-contained Python process with embedded storage.
