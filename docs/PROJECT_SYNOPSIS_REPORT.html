1. Project Title

NEXUS-BTC: Network–Entity eXplainable Unified Surveillance and Digital-Forensics Platform for Bitcoin

2. Abstract

NEXUS-BTC addresses the escalating challenge of illicit Bitcoin transaction traffic, where sophisticated laundering topologies such as multi-hop peeling chains, mixing cycles, and layering fan-outs evade conventional inspection. Existing commercial blockchain analytics platforms depend on external cloud APIs, violating air-gapped security protocols, while machine learning models often operate as black boxes conflating threat severity with evidentiary confidence. To overcome these limitations, this project develops an offline-first, air-gapped forensic surveillance system utilizing multi-format ingestion (CSV, JSON, NDJSON, XML) with defensive quarantine isolation. The platform implements near-linear time disjoint-set Union-Find entity clustering with automated CoinJoin suppression to consolidate pseudonymous wallet addresses into coherent real-world entities. An in-memory heterogeneous directed multigraph models transaction flow, over which a value-aware Best-First search algorithm traces tainted funds and detects cyclical wash trading without combinatorial explosion. A multi-view ensemble combining Platt-calibrated Random Forests, Isolation Forests, and temporal Z-score detectors evaluates threat probability independently from epistemic evidence completeness, yielding orthogonal Risk and Confidence scores (0–100). Flagged alerts are justified via multimodal Explainable AI incorporating SHAP TreeExplainer feature attributions, counterfactual motif ablation deltas, and chronological evidence dossiers. Evaluated across 55 automated integration tests, NEXUS-BTC demonstrates sub-second graph analysis over 10,000 edges without network connectivity, providing law enforcement with transparent, court-admissible forensic intelligence.

Keywords: Bitcoin Forensics, Entity Clustering, Explainable AI (XAI), Laundering Motif Detection, Graph Intelligence, Offline Surveillance.

3. Introduction

The pseudonymous design of Bitcoin, governed by an immutable unspent transaction output (UTXO) ledger, was conceived to provide decentralized financial sovereignty without centralized gatekeepers. However, this architectural pseudonymity has increasingly been weaponized by transnational syndicates, ransomware operators, darknet market vendors, and sanctioned entities to transfer illicit proceeds at global scale. To conceal fund origins, criminal actors deploy intricate topological evasion strategies, including high-frequency peeling chains that peel off micro-payments while forwarding change outputs, CoinJoin protocols that pool multi-party funds to disrupt ownership attribution, and rapid multi-hop layering.

Investigating these transactions is of paramount national security and law-enforcement importance, directly aligned with National Technical Research Organisation (NTRO) and Smart India Hackathon (SIH) 2026 mandates. In legal jurisprudence, evidentiary standards require that digital artifacts presented in court possess an unbroken, verifiable chain of custody accompanied by mathematically defensible reasoning. Current commercial forensic platforms fail this standard because they rely on proprietary cloud APIs that inadvertently leak sensitive investigative case hashes to third-party vendors. Furthermore, prevailing machine learning models function as uncalibrated black boxes that produce single heuristic threat scores without explaining which specific transaction attributes contributed to the alert.

NEXUS-BTC operates in this investigative context as a fully air-gapped, zero-daemon digital forensics and network surveillance workstation. Designed specifically for forensic laboratories and intelligence analysts, it unifies peer-to-peer network broadcast telemetry with blockchain graph algorithms. By ensuring 100% offline autonomy, executing mathematical entity resolution via disjoint-set structures, and providing transparent SHAP feature attributions and counterfactual reasoning, NEXUS-BTC establishes a robust technological foundation for court-admissible cryptocurrency surveillance.

4. Problem Statement

Modern law enforcement and national intelligence agencies face severe operational impediments in monitoring illicit Bitcoin transaction traffic due to sophisticated laundering obfuscations such as peeling chains, multi-input mixing, and rapid layering fan-outs. Existing commercial cryptocurrency investigation suites require mandatory cloud connectivity, violating air-gapped security protocols required in forensic clean-rooms and exposing confidential operational queries to external third parties. Furthermore, available anomaly detection systems rely on opaque, uncalibrated black-box models that conflate threat severity with evidentiary completeness, producing unsubstantiated risk scores that cannot withstand legal cross-examination in judicial proceedings. NEXUS-BTC solves these limitations by delivering a production-grade, 100% offline surveillance platform that combines deterministic disjoint-set entity clustering, topological motif recognition, orthogonal risk versus confidence scoring, and multimodal explainable AI.

5. Objectives

  1. To design a robust, multi-format offline ingestion pipeline supporting CSV, JSON, NDJSON, and XML formats with defensive Pydantic V2 schema sanitization and non-crashing quarantine isolation for corrupted records.
  2. To develop a near-linear time $\mathcal{O}(m \cdot \alpha(n))$ Union-Find disjoint-set entity clustering algorithm with automated CoinJoin suppression to collapse pseudonymous addresses into unified real-world entities.
  3. To implement an in-memory heterogeneous directed multigraph engine and a value-aware Best-First search fund tracer capable of tracking multi-hop laundering chains and isolating cyclical wash trading without combinatorial explosion.
  4. To deploy a calibrated multi-view anomaly detection ensemble integrating Platt-calibrated Random Forests, Isolation Forests, and temporal Z-score detectors providing mathematically orthogonal Risk (0–100) and Confidence (0–100) scores.
  5. To evaluate and explain forensic alerts through multimodal Explainable AI (SHAP TreeExplainer feature attributions, counterfactual motif ablation deltas, and chronological evidence dossiers) via an interactive, air-gapped web command center.

7. Existing System and Proposed System

7.1 Existing System

Existing cryptocurrency surveillance predominantly relies on commercial enterprise intelligence platforms (e.g., Chainalysis Reactor, Elliptic Investigator, TRM Labs) or fragmented open-source Python research scripts. In these systems, transaction monitoring is conducted through centralized cloud platforms that ingest ledger dumps and assign proprietary risk indices based on static database cluster lookups.

  • Mandatory Cloud API Lock-In: Platforms require continuous internet access to proprietary cloud servers, directly violating air-gap security protocols of intelligence agencies and leaking confidential transaction queries.
  • Black-Box Uncalibrated Scoring: Threat scores are emitted without local feature-level attributions or counterfactual evidence, rendering alerts vulnerable to legal challenges during judicial proceedings.
  • Conflation of Risk and Confidence: Systems merge threat probability and evidentiary certainty into a single scalar value, triggering severe false-positive alerts on transactions with sparse network evidence.
  • Fragile Ingestion Architecture: Open-source scripts crash when encountering malformed hexadecimal TXIDs, negative satoshi values, or schema variations across CSV/XML dumps.
  • Prohibitive Infrastructure Overhead: Tools demand high-memory cloud clusters or heavyweight multi-container databases (Neo4j, PostgreSQL, Redis) unsuited for local field laptop deployment.

7.2 Proposed System (NEXUS-BTC)

NEXUS-BTC provides a self-contained, air-gapped, zero-daemon forensic workstation engineered with Python 3.11, FastAPI, React 18, Cytoscape.js, and SQLite WAL mode. It unifies ingestion, entity resolution, graph intelligence, calibrated anomaly detection, and multimodal explainability into a coherent offline architecture.

  • Strict 100% Air-Gapped Autonomy: The entire software stack operates with zero external network calls, zero remote CDNs, and zero Google Fonts, utilizing embedded MaxMind MMDB databases and self-hosted web assets.
  • Non-Crashing Defensive Quarantine: Ingestion pipelines validate payloads against strict Pydantic V2 schemas, isolating corrupted records into quarantine storage with error reason tags while maintaining continuous processing.
  • Orthogonal Risk vs. Confidence Metrics: Risk (0–100, measuring pattern severity) is mathematically separated from Confidence (0–100, measuring evidence completeness and model agreement), preventing premature investigative escalations.
  • Value-Aware Best-First Fund Tracing: Max-heap priority queue graph traversal prunes dust outputs below relative value thresholds and isolates cyclical wash-trading loops without combinatorial explosion.
  • Multimodal Explainable AI (XAI): Combines SHAP TreeExplainer feature attributions, counterfactual motif ablation deltas, and step-by-step chronological evidence chains ready for legal presentation.

8. Methodology / System Design

The forensic workflow of NEXUS-BTC is organized into a deterministic 10-stage execution pipeline designed to guarantee reproducibility, mathematical rigor, and forensic integrity:

  1. Multi-Format Ingestion & Quarantine: Ingests transaction and peer telemetry dumps across CSV, JSON, NDJSON, and XML. Malformed records are tagged (e.g., FLAG_MALFORMED_TXID, FLAG_NEGATIVE_AMOUNT) and quarantined without interrupting ingestion.
  2. Network-Blockchain Telemetry Correlation: Correlates on-chain transaction timestamps with captured P2P packet broadcasts ($\Delta t = |t_{tx} - t_{net}|$), resolving Autonomous System Numbers (ASN) and geographic coordinates via offline MaxMind databases.
  3. Disjoint-Set Entity Clustering: Applies Satoshi's multi-input ownership heuristic using Union-Find with path compression and union-by-rank running in near-linear time $\mathcal{O}(m \cdot \alpha(n))$. Incorporates a CoinJoin detector ($\ge 3$ inputs, $\ge 3$ outputs, equal output amounts within $\pm 1\%$) to suppress false cluster merging.
  4. Heterogeneous Graph Construction: Instantiates an in-memory directed multigraph (NetworkX MultiDiGraph) modeling addresses, transactions, and entity clusters, calculating PageRank ($\alpha=0.85$), degree centralities, and ego-network densities in under 100 ms for 10,000 edges.
  5. Structural Laundering Motif Detection: Executes deterministic pattern matchers scanning for Peeling Chains ($V_{peel} \le 0.05 V_{in}, V_{change} \ge 0.80 V_{in}, \ge 5$ hops), Mixing cycles, Smurfing fan-outs, and Consolidation fan-ins.
  6. Multi-View Anomaly Detection Ensemble: Fuses predictions from an unsupervised Isolation Forest (contamination=0.05), a supervised Random Forest calibrated via Platt's sigmoid scaling (CalibratedClassifierCV), and a rolling Z-score temporal burst detector.
  7. Calibrated Risk & Confidence Fusion: Evaluates threat probability independently from data completeness and inter-model consensus, categorizing alerts into Priority Alerts, Investigative Leads, Data Gaps, and Normal Noise.
  8. Value-Aware Best-First Fund Tracing: Executes forward and backward priority-queue traversals prioritized by output value ($-amount\_btc$), automatically pruning dust paths and isolating circular wash-trading loops (CYCLE endpoints).
  9. Multimodal Explainable AI (XAI): Computes exact local SHAP feature attributions and counterfactual sensitivity deltas ($\Delta \text{Risk}$ resulting from motif ablation), generating court-admissible forensic evidence chains.
  10. Tactical Command Center Presentation: Streams alerts, topological subgraphs, and dossier drawers to an offline React/TypeScript dashboard powered by Cytoscape.js.

9. Modules

  • Multi-Format Ingestion & Quarantine Module: Ingests transaction and peer telemetry dumps across CSV, JSON, NDJSON, and XML formats, validating records via Pydantic V2 and routing malformed rows to quarantine storage without pipeline disruption.
  • Network Telemetry & GeoIP Correlation Module: Correlates on-chain transactions with P2P packet captures, resolving geographic locations and Autonomous System Numbers (ASN) using an offline MaxMind MMDB database.
  • Disjoint-Set Entity Clustering Module: Executes Satoshi's multi-input heuristic using Union-Find with path compression in $\mathcal{O}(m \cdot \alpha(n))$ time, incorporating CoinJoin detection to prevent false entity merging.
  • Heterogeneous Graph Intelligence Engine: Constructs an in-memory directed multigraph (NetworkX MultiDiGraph) of transactions, addresses, and clusters, computing PageRank, centrality, and ego-network density in <100ms.
  • Structural Laundering Motif Detection Engine: Algorithmic state-machines identifying peeling chains, mixing cycles, smurfing fan-outs, and consolidation fan-ins based on deterministic flow criteria.
  • Multi-View AI/ML Anomaly Ensemble: Integrates Platt-calibrated Random Forests, unsupervised Isolation Forests, and temporal Z-score burst detectors to calculate true posterior threat probabilities.
  • Orthogonal Risk & Confidence Scoring Engine: Computes separate Risk (0–100) and Confidence (0–100) scores, mapping alerts onto an investigative priority matrix to distinguish genuine threats from data gaps.
  • Value-Aware Best-First Fund Tracer: Traverses UTXO transaction graphs along highest-value forward edges using a priority-queue max-heap, automatically pruning dust outputs and detecting cyclic wash trading.
  • Explainable AI (XAI) & Counterfactual Engine: Computes exact SHAP TreeExplainer feature attributions, generates counterfactual delta simulations, and compiles court-admissible forensic evidence chains.
  • Synthetic Scenario Generation Studio: Generates deterministic, seed-locked Bitcoin laundering scenarios across all core motifs to benchmark detection models under reproducible conditions.
  • Tactical Forensic Web Command Center: Delivers an offline React 18, TypeScript, and Cytoscape.js interface featuring interactive graph exploration, real-time alert queues, and dossier review drawers.
